<h1 align="center">Blossom · Monday Dev Sync</h1>

<p align="center">
  <strong><a href="https://blossom-ag.github.io/blossom-monday-checklist/">Open the live checklist →</a></strong>
</p>

A clickable weekly agenda for the Blossom Monday developer meeting — run it top-to-bottom, check items off as you go.

- ✅ **Clickable** — tap any row to check it off; the progress bar fills as you go.
- 🗓️ **Auto-clears each new week** — always opens fresh on Monday (shows "Week of …").
- 💾 **Finish & save** archives the week into a **Past weeks** history you can reopen anytime.
- 📴 **No login, no backend** — runs entirely in your browser. Checks save on that device.

Pin the live link in a recurring weekly Google Task, and each Monday: open → check off → **Finish & save**.

The agenda covers prep (initiative health + scorecard), then the meeting: Triage → in-flight review → review queue → cycle planning → estimates → status hygiene → close-out → initiatives & projects health. Estimate scale is Fibonacci (1–21).
